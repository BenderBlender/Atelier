# Необязательные компоненты помощника

В Git-репозитории нет сторонних EXE, токенов и готовых профилей входа. Рисование и сохранение проектов не требуют файлов в этой папке.

## ChatGPT / Codex

Atelier запускает официальный исполняемый компонент Codex через встроенный в приложение мост. Отдельный HTTP-сервер или соседний проект не нужен. [Официальный репозиторий и установка Codex](https://github.com/openai/codex).

Порядок поиска: `runtime/codex.exe`, установленный Codex в `%LOCALAPPDATA%/OpenAI/Codex/bin`, затем исполняемый файл в `PATH`. Можно явно выбрать `codex.exe` в настройках подключения Atelier. Если используете локальную копию из официальной поставки, держите её вспомогательные файлы рядом с ней; не копируйте файлы авторизации.

Откройте «Помощник → Настройки → Подключение», проверьте вход или выполните вход через браузер. Авторизацию обслуживает сам Codex. Генерация изображений требует версии Codex и аккаунта с соответствующей возможностью. Произвольная версия CLI не обязательно поддерживает использованный в Atelier инструмент изображений. Локальная проверка разработки выполнялась с Codex `0.167.0-alpha.4.1`; этот исполняемый комплект не распространяется здесь.

## Higgsfield

Возьмите Windows amd64-поставку из [официальных релизов Higgsfield CLI](https://github.com/higgsfield-ai/cli/releases) и поместите `hf.exe` в эту папку. Atelier 0.17.1 проверялся с CLI **1.2.3**. [Документация CLI](https://github.com/higgsfield-ai/cli).

Затем выберите Higgsfield в помощнике, нажмите «Войти в Higgsfield» и выберите рабочее пространство. Вход через MCP в другом приложении автоматически не переносится в Atelier.

Каталог `presets/higgsfield-models.json` — снимок доступных моделей для интерфейса, а не гарантия доступности модели любому аккаунту. Перед генерацией приложение проверяет схему через CLI. При изменении формата команд или каталога может потребоваться обновление интеграции.

## OpenAI API

Исполняемые файлы не требуются. Введите API-ключ в настройках подключения или задайте `OPENAI_API_KEY`, укажите доступные вашему аккаунту модели. Ключ остаётся в памяти сеанса и не записывается в `.atelier`. Использование API оплачивается отдельно от подписки ChatGPT.
