# Помощник Atelier

Помощник — плавающее окно с двумя режимами: **«Чат · помощник Atelier»** и **«Изображение · генерация»**. Enter отправляет сообщение, Shift+Enter добавляет строку. Меню с тремя точками открывает новый диалог и историю. Закрытие окна скрывает его; выполняющийся запрос продолжает работу.

## Чат и действия

Можно обсуждать скетч и поручать действия, например:

- «Разложи выбранные референсы в три колонки».
- «Добавь голубой слой построений с прозрачностью 30%».
- «Настрой кристалл Эшера и покажи скрытые линии на 20%».
- «Посмотри мой скетч и предложи, что улучшить. Пока ничего не меняй».

Агент получает описание текущего состояния и вызывает ограниченный набор команд Atelier: столы, листы, папки, кисти, направляющие, пины, сетки, простые штрихи и прямоугольные выделения Inpaint. Изменения рисунка поддерживают отмену. Удаление и очистка требуют применения предложенных команд; изменение стола во время ответа также останавливает автоматическое применение. Произвольные команды ОС и внешние сообщения через агента не выполняются.

Чат использует Codex/ChatGPT или OpenAI API. Higgsfield используется для изображений, а не для диалога агента.

## Изображения

Выберите лист, переключитесь на «Изображение · генерация» и напишите запрос. Результат появляется новым листом над исходным, а также в переписке. Для следующей доработки выберите нужный результат и отправьте новый запрос.

Если «Улучшить мой промпт» выключено, текст пользователя передаётся без переписывания, перевода и добавления выбранного стиля. Быстрый запуск художественного пресета применяет стиль явно. В режиме Inpaint к запросу отдельно добавляются технические условия локального редактирования.

В `presets/assistant/` находятся десять редактируемых JSON-пресетов: карандашная кинораскадровка, мастерский графит, перо и штриховка, кисть и тушь, ясная линия, динамичный комикс, кинематографический свет, промышленный дизайн, постановочный эскиз и нуар. Справочные имена и ссылки в пресетах описывают профессиональный контекст; тексты заданий описывают приёмы рисунка.

## Inpaint

1. Выберите исходный лист и режим **«Inpaint · только выделенная область»**.
2. Закрасьте область кистью или обведите прямоугольник. Alt вычитает область; очистка маски не стирает рисунок.
3. Настройте мягкость края. Согласование фона уменьшает заметность перехода.
4. Для небольших деталей включите **«Больше деталей · крупный план»**: область с контекстом увеличивается для обработки, затем возвращается в прежнем масштабе. Размер всего листа сохраняется.
5. Опишите изменение и отправьте запрос.

Модель может ошибаться в анатомии, предметах и перспективе. Увеличение фрагмента не гарантирует правильной конструкции. Atelier ограничивает вставку маской локально, чтобы остальной лист не зависел от того, как модель перерисовала фон. Неизменённый исходник остаётся под новым листом.

## Подключения

Инструкции по компонентам находятся в [runtime/README.md](../runtime/README.md). Подписка, API и Higgsfield — независимые варианты авторизации и оплаты; приложение не переключается между ними автоматически.

В интерфейсе Higgsfield по умолчанию выбраны **Seedream 5.5 / Auto / 2K**. Параметры зависят от модели и доступа аккаунта. Auto сохраняет пропорции исходника либо выбирает ближайший поддерживаемый формат. Для несовместимого формата Inpaint приложение останавливает запрос до генерации. «Получить результат последнего задания» проверяет уже отправленную задачу без создания новой.

Генерация через мост Codex не обещает совпадения с веб-версией ChatGPT: маршрутизация и доступные инструменты могут отличаться. Для API можно указать доступные модели в настройках.

## Какие данные передаются

При обычном рисовании сеть не нужна. При отправке в чат сервис получает сообщения, описание столов и, если включено «Показывать выбранный скетч помощнику», уменьшенный снимок листа. Для генерации передаются запрос и исходное изображение; для Inpaint — также маска или изображение с обозначением области. Сервис обрабатывает их в соответствии со своими условиями.

В `data/` локально хранятся история, настройки, рабочие файлы задач и резервные копии. Они исключены из Git. Токены Codex и Higgsfield обслуживаются их официальными компонентами; ключ OpenAI API приложение не сохраняет в проект. Не публикуйте свою папку `data/` при отправке отчёта об ошибке.
