# Разработка и проверки

Основная проверенная среда — Windows x64 и Python 3.10. Зависимости перечислены в `requirements.txt`: PySide6 6.8.3, NumPy, SciPy и Numba 0.61.2. GPU не требуется: ускоренные кисть и геометрия используют JIT-компиляцию на CPU, отрисовка — Qt.

## Структура

| Путь | Назначение |
|---|---|
| `main.py`, `sketchpad/app.py` | Запуск, главное окно, команды и настройки |
| `sketchpad/brush*.py` | Контакт грифеля, фактура бумаги, пигмент, клячка, ускорение |
| `sketchpad/board.py`, `model.py` | Холст, жесты, история отмены, листы и формат проекта |
| `sketchpad/tablet.py`, `raw_input.py` | WinTab и независимый ввод относительной мыши |
| `sketchpad/perspective*.py`, `crystal*.py` | Объёмные направляющие, проекции и видимость поверхностей |
| `sketchpad/desks.py`, `navigation.py` | Несколько столов, закладки листов и папки |
| `sketchpad/reference_window.py` | Плавающий вид стола и просмотр изображения без рамки |
| `sketchpad/assistant*.py`, `agent*.py` | Чат, команды агента и подключения генерации |
| `sketchpad/inpaint.py` | Маски, локальные фрагменты и переход на границе |
| `presets/` | Художественные задания и каталог моделей Higgsfield |
| `tests/` | Автоматические проверки без платных запросов |
| `scripts/` | Установка и подготовка демонстрационных скриншотов |

## Тесты

```powershell
$env:QT_QPA_PLATFORM='offscreen'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Для первоначальной публикации 0.17.1 локально пройдены **195 тестов**. Они проверяют геометрию карандаша и клячки, давление/наклон, сохранение проектов, ввод, поворот, прозрачность, Alt-слои, маски, перспективу, команды агента и режим фокуса референсов. Сетевые подключения в тестах заменены контролируемыми ответами; аккаунты и платная генерация не требуются.

`.github/workflows/tests.yml` выполняет набор на Windows и Python 3.10. Эти проверки не заменяют оценку ощущения физического пера, многомониторного ввода или качества новой генерации.

Для сравнения с резервным движком:

```powershell
$env:ATELIER_BRUSH_BACKEND='numpy'
.\.venv\Scripts\python.exe main.py
```

## Скриншоты

```powershell
$env:QT_QPA_PLATFORM='offscreen'
.\.venv\Scripts\python.exe -m scripts.capture_screenshots
```

Скрипт открывает отдельное тестовое состояние приложения, использует временную папку настроек, рисует образцы через текущий движок и сохраняет снимки в `docs/screenshots/`. Существующие столы, история пользователя и аккаунты не загружаются. Генерация не вызывается; для демонстрации помощника используются сохранённые примеры из `docs/examples/`.

## Формат и личные данные

`.atelier` — ZIP-контейнер с описанием документа и PNG рисунков. Текущая версия формата — 4; поддерживается чтение версий 1–4. У каждого стола своя история отмены. Плавающий вид использует тот же документ и историю, а режим фокуса меняет только геометрию окна.

В Git намеренно не входят `.venv/`, `data/`, проекты `.atelier`, исследовательские материалы, локальные журналы и сторонние EXE. Публикуйте новые демонстрации только после проверки отсутствия личных данных.

## Отчёт об ошибке

В [Issues](https://github.com/BenderBlender/Atelier/issues) укажите версию Atelier, Windows, модель планшета и драйвера, выбранный режим ввода и короткие шаги воспроизведения. Для проблемы с кистью полезны значения нажима/наклона из диагностики. Для помощника достаточно провайдера, модели и текста ошибки; ключи, токены и историю личных запросов прикладывать не нужно.
