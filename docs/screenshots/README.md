# Скриншоты и демонстрационные материалы

Снимки созданы в Atelier 0.17.1 скриптом `scripts/capture_screenshots.py` на отдельном демонстрационном состоянии.

- `workspace.png`, `perspective.png`, `references.png`, `focus.png`, `assistant.png` — снимки настоящих виджетов приложения, без дорисованного интерфейса.
- `pencil.png`, `papers.png` — образцы, рассчитанные текущим карандашным движком Atelier.
- `../examples/sketch.png` — простой программно нарисованный исходник из проверки генерации.
- `../examples/refined.png` — ранее полученный результат ИИ-генерации по этому исходнику. Он демонстрирует возможность помощника, а не ручной карандашный штрих.

Переписка на скриншоте помощника содержит явно помеченный демонстрационный текст и сохранённый результат. При подготовке снимков новые запросы в сервисы не отправлялись. Скриншоты не содержат личных проектов, имён аккаунтов, ключей или токенов.
